# Данные игры

[English](../en/game-data.md) | **Русский**

В движке нет ни одного файла оригинальной игры. Он читает данные **вашей копии** Need for Speed: Porsche
Unleashed и ничего в ней не меняет. В браузерной сборке данные подготавливаются на сервере и отдаются по
HTTP; браузер посетителя их только скачивает.

## Что нужно

Из установленной игры — из папки, где лежит `nfs5.exe`:

| Файл / папка | Обязательно | Зачем |
|---|---|---|
| `GameData/` | да | трассы, машины, физика, звуки |
| `FEData/` | да | меню, шрифты, тексты, ролики |
| `nfs5.exe` | нет | из него получается `madtables.bin` для вступительных роликов (сам он не запускается); без совместимых таблиц ролики пропускаются |
| `fe.txt` | нет | файл настроек оригинала; без него используются настройки по умолчанию |
| `nfs5.ini` | нет | настройки патча Verok с теми же ключами и значениями по умолчанию, что у пропатченного оригинала |
| `version.txt` | нет | версия игры (`3.5`), используется проверкой версии в сети; браузер подставляет `3.5`, если файла нет |

## Подготовка данных для веба

Из корня репозитория:

```sh
make web-data GAME_DIR=/path/to/game
make web-data GAME_DIR=/path/to/game MOVIE_EXE=/path/to/Porsche.exe
make web-data GAME_DIR=/path/to/game EXTRA_FILES=/path/to/extra.txt
```

Цель копирует только те файлы, которые читает браузерная сборка, отбрасывает файлы, ненужные ни одному
крейту, проверяет каждый подходящий exe оригинальной игры и получает `madtables.bin` существующим
Rust-парсером. `MOVIE_EXE` задаёт exe вручную, `EXTRA_FILES` добавляет корневой файл вне `GAME_DIR`.

Результат — папка `web-data/`. В ней `manifest.json` с путями без учёта регистра, размерами, группами и
хешами SHA-256, а также объекты с содержимым, которые браузер скачивает и проверяет независимо. Держите эту
папку вне Git: данные оригинальной игры и производные таблицы роликов никогда не коммитятся.

Упаковщик также создаёт сжатые копии `.gz`, если они уменьшают объём передачи. Nginx и локальный
сервер отдают их браузеру автоматически; SHA-256 проверяется после распаковки. Для уже подготовленных
данных повторите упаковку и переносите `.gz` вместе с объектами на сервер. WebAssembly скачивается
и компилируется параллельно с ассетами после нажатия Start.

При первом запуске не скачиваются фотографии хроники, изображения Showcase и ролики,
не используемые во вступлении и стартовом меню. Они загружаются перед показом выбранного
изображения или ролика. Для предпросмотра автомобиля загружается его семейство моделей;
остальные модели подготавливаются перед первой гонкой, поскольку выбор соперников и
трафика пока синхронный. Короткие звуковые банки и стартовая трасса Alps остаются в начальной
загрузке. При ошибке загрузки можно повторить запрос без перезапуска игры.
Новая упаковка `web-data` для отложенной загрузки не нужна: достаточно обновить веб-сборку.

Сервер монтирует подготовленную папку рядом с приложением только для чтения. Браузер видит её под
`/data/`, а движку игровые файлы доступны под `/game`. Никогда не отдавайте напрямую репозиторий или папку
установленной игры.

## `nfs5.ini`

Движок читает `nfs5.ini` из данных игры с теми же ключами, значениями по умолчанию и действием, что у
пропатченного оригинала; без файла действуют значения по умолчанию. Секция `[NFS5]`:

| Ключ (по умолчанию) | Что делает |
|---|---|
| `Language=English` | `English`, `French`, `German`, `Italian`, `Spanish`, `Swedish`, `PortBrzl` (регистр любой); всё прочее — английский |
| `NoMovies=0` | 1 пропускает вступительные ролики |
| `Fog=1` | 0 выключает погодный туман |
| `Filtering=1` | 0 — текстуры выбираются по ближайшему тексельному значению вместо билинейной фильтрации |
| `CarControl=0` | 1 оставляет руль, газ и тормоз живыми после финиша машины игрока |

`ThrashDriver`, `WindowedMode`, `SingleProcAffinity`, `CpuLimit` и `NoErrorReporting` относятся к запуску
самого оригинала и игнорируются.
