Неофициальная открытая браузерная реализация движка **Need for Speed: Porsche Unleashed** (PC, 2000).
Работает в современных настольных и мобильных браузерах из WebAssembly: без установки, Wine, эмуляторов и
оригинального exe. Физика, соперники и трафик, карьера «Эволюция», «Гонщик-испытатель» и оригинальные меню
играются как в оригинале. Данные игры загружаются по HTTP, прогресс хранится в IndexedDB браузера.

Независимая реализация, написанная с нуля на Rust (wgpu с WebGPU и WebGL2) и воспроизводящая поведение
оригинала.

> **Нужна своя копия игры.** Ни одного файла оригинальной игры нет ни в репозитории, ни в сборках.
> Проект не связан с Electronic Arts, Eden Games и Porsche AG; «Need for Speed» и «Porsche» — товарные знаки
> их владельцев и упоминаются здесь только для того, чтобы сказать, для какой игры этот движок.

## Игра в браузере

Движок компилируется в `wasm32-unknown-unknown` и полностью работает в браузере. В готовую игру можно
играть на домашней странице проекта: [porsche.nfs.place](https://porsche.nfs.place). Чтобы запустить свою
копию, см. [сборку и размещение в браузере](packaging/web/README.md). Мультиплеер запланирован отдельным
этапом и в браузерной сборке пока недоступен.

На сенсорных устройствах меню и гонка используют разные экранные кнопки.
В гонке можно переводить палец между крупными кнопками руля или педалями без
отрыва от экрана. Нижние приборы поднимаются над управлением, а панель
сохранений, языка и полного экрана открывается кнопкой ☰. Нажатие на активное
игровое поле ввода вызывает экранную клавиатуру устройства; ограничения игры
на символы и длину имени сохраняются.

## Быстрый старт

Чтобы запустить игру у себя:

1. Поставьте цель wasm и подходящий wasm-bindgen CLI: `make setup-web`.
2. Подготовьте данные оригинальной игры: `make web-data GAME_DIR=/path/to/game`.
3. Соберите браузерную версию: `make build-web`.
4. Запустите локальный сервер: `make serve`, затем откройте `http://127.0.0.1:8080`.

Подробности и требования к размещению: [браузерная сборка](packaging/web/README.md).

### Мод-паки

На экране запуска можно выбрать паки, заменяющие файлы оригинальной игры.
При конфликте приоритет имеет последний выбранный пак в списке. Для изменения
набора после запуска перезагрузите страницу. Сохранения общие для всех наборов.

В каталоге пака создайте `mod.json` и положите заменяемые файлы по путям от корня
игры, например `GameData/CarModel/993.crp`:

```json
{
  "id": "custom-cars",
  "name": "Новые машины",
  "description": "Замена моделей и текстур машин",
  "enabled_by_default": false
}
```

```sh
make mod-pack MOD_DIR=/path/to/custom-cars
make deploy-mod MOD_DIR=/path/to/custom-cars DEPLOY_SSH_HOST=server.example \
  DEPLOY_SSH_USER=admin DEPLOY_DATA_DIR=/srv/open-unleashed/web-data
```

Первая команда собирает пак в `WEB_DATA` (по умолчанию `web-data`), вторая собирает
и отправляет только этот пак на сервер. Для деплоя нужны SSH и rsync, на сервере —
rsync, Python 3 и право записи в каталог данных, смонтированный как `/data`.
Ограниченный SSH-ключ для деплоя Docker-образов для этого не подходит.
Оригинальный манифест и исходная установка не изменяются; перезапуск контейнеров
для обновления паков не нужен. Новые паки добавляются в конец списка, обновления
существующего `id` сохраняют порядок. Подробности формата и удаления паков:
[инструкция для браузерной версии](packaging/web/README.md#mod-packs).
